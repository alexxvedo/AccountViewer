│ Flujo de Datos Detallado                                                                                                                                                                                       │
│                                                                                                                                                                                                                │
│ 1. Usuario abre página de cuenta → Frontend detecta posiciones abiertas                                                                                                                                        │
│ 2. Por cada símbolo único → POST /accounts/:id/request-chart                                                                                                                                                   │
│ 3. Backend → Añade comando a cola del EA                                                                                                                                                                       │
│ 4. EA polls /ea/commands → Recibe request_chart_data                                                                                                                                                           │
│ 5. EA ejecuta CopyRates() → Obtiene 200 barras históricas                                                                                                                                                      │
│ 6. EA envía a /ea/chart-data → Backend cachea                                                                                                                                                                  │
│ 7. Frontend polls /chart-data/:symbol → Obtiene datos, renderiza gráfico                                                                                                                                       │
│ 8. Cada segundo → Frontend recibe current_price en /accounts/:id/live                                                                                                                                          │
│ 9. Frontend actualiza última vela → Gráfico en tiempo real                                                                                                                                                     │
│                                                                                                                                                                                                                │

│ Consideraciones Técnicas                                                                                                                                                                                       │
│                                                                                                                                                                                                                │
│ Caché de Datos                                                                                                                                                                                                 │
│                                                                                                                                                                                                                │
│ - Clave: {accountId}:{symbol}:{timeframe}                                                                                                                                                                      │
│ - TTL: 5 min para timeframes <= H1, 30 min para D1                                                                                                                                                             │

│                                                                                                                                                                                                                │
│ Timeframes MT5                                                                                                                                                                                                 │

│ ├──────────┼────────────┼─────────┤                                                                                                                                                                            │
│ │ M5       │ PERIOD_M5  │ 5       │                                                                                                                                                                            │
│ ├──────────┼────────────┼─────────┤                                                                                                                                                                            │
│ │ M15      │ PERIOD_M15 │ 15      │                                                                                                                                                                            │
│ ├──────────┼────────────┼─────────┤                                                                                                                                                                            │
